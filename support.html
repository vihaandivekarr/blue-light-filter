Support

Having trouble? Most problems are solved by one of the answers below.

Getting started

  1. Install Blue Light Filter from the Chrome Web Store.
  2. Click the puzzle-piece icon in Chrome's toolbar and pin Blue Light Filter.
  3. Click the orange moon icon to open the controls.
  4. That's it. The filter starts on every open tab right away.

Common questions

Chrome says it's "not trusted by Enhanced Safe Browsing."

Chrome shows this for every extension from a new developer, if you have Enhanced Safe Browsing turned on. It isn't about anything Blue Light Filter does. Google trusts developers automatically once they've followed the Chrome Web Store rules for a few months. To install anyway, click Continue to install. Blue Light Filter collects no data, makes no internet requests, and never sends you to other websites. See the privacy policy.

The filter isn't showing on a page.

Click the orange moon icon. The message at the top of the popup tells you why: the filter might be switched off, paused, turned off for that site, or waiting for your schedule.

How do I use different settings on different sites?

Go to the site, open the popup, and under On [site name] pick Use special settings for this site (then move the sliders) or Never filter this site. You can see and edit all your site rules on the All settings page.

It doesn't work on the New Tab page or Chrome settings.

Chrome doesn't let any extension run on its own pages (like the New Tab page, chrome:// pages, and the Chrome Web Store). This is a Chrome safety rule, not a bug.

Can it tint my whole screen, not just Chrome?

No. Chrome extensions can only change web pages. For your whole screen, use the setting built into your computer: Night Shift on Mac (System Settings → Displays) or Night light on Windows (Settings → System → Display).

How does the schedule work?

Open All settings, choose Only between these times, and pick a start and end time. It works overnight (for example 8:00 PM to 7:00 AM). You can also have it fade in and out gradually.

The colors look too strong or too weak.

Try the presets first. Then adjust Filter strength and Warmth: further right on Warmth blocks more blue light. Use Dim screen if a page is too bright.

Does it work on videos?

Yes, including fullscreen videos.

Are there keyboard shortcuts?

Alt+Shift+B turns the filter on or off, and Alt+Shift+Up/Down changes the strength. You can change them at chrome://extensions/shortcuts.

Does it collect my data?

No. See the privacy policy.
